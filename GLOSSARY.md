# Glossary

The words WindowHop and its code use for one thing each.

| Term | Definition | Do not write |
| :--- | :--- | :--- |
| Switcher | The panel the shortcut opens, with one tile per top-level window. | picker, overlay, HUD |
| Tile | One window's entry in the switcher: its preview or icon, and its title. | card, cell, thumbnail (for the whole tile) |
| Window Previews | The switcher style whose tiles show a live capture of each window. | thumbnails mode |
| App Icons | The switcher style whose tiles show the application's icon. | icon mode |
| Shortcut | The key combination that opens the switcher and moves through it. | hotkey, binding |
| Tracked app | A running application whose windows WindowHop observes. | watched app, monitored process |
| Capture budget | The limit on window captures that run at once. | capture pool, throttle |
