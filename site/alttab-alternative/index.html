WindowHop, AltTab or the Mac’s own ⌘Tab?

The Mac’s ⌘Tab stops at the app. AltTab reaches every window, with search and some styles in a paid Pro version. WindowHop reaches every window with everything free, no Screen Recording for its default style, and no telemetry.

What each switcher does.

  • Everything free, no Pro version
  • No Screen Recording for the default style
  • No telemetry, no crash reports
  • ⌘Tab falls back to Apple’s if WindowHop stops

Which one fits you

Choose by how you work.

Keep the Mac’s ⌘Tab if

  • You keep one window per app most of the time.
  • You want nothing to install and no permission to give.

Choose WindowHop if

  • You keep several windows of the same app open.
  • You want ⌘Tab itself to reach them, with nothing to set up.
  • You want every feature free, without Screen Recording or telemetry.
  • You want Apple’s ⌘Tab back at once if WindowHop ever stops.
  • You have an Apple silicon Mac with macOS 26 or later.

Choose AltTab if

  • You want to search windows by typing, and a Pro licence is fine.
  • You want more styles, sizes and shortcuts.
  • You have an Intel Mac or a macOS version older than macOS 26.

WindowHop and AltTab are free and open source under GPL-3.0. WindowHop keeps AltTab’s attribution and history, and credits Louis Pontoise (lwouis) and the AltTab contributors.
